# Комплект спикера GreenPlan AI (приложение к презентации, не слайды)

## 1. Как собрать pptx / pdf из docs/PRESENTATION.md

Файл слайдов совместим с Marp (слайды разделены ---, заметки спикера — в HTML-комментариях,
код-блоки оформлены fence ~~~, что Marp и pandoc понимают).

~~~bash
# вариант A: Marp CLI (нужен Node.js)
npx @marp-team/marp-cli docs/PRESENTATION.md --pptx -o docs/GreenPlan_AI.pptx
npx @marp-team/marp-cli docs/PRESENTATION.md --pdf  -o docs/GreenPlan_AI.pdf

# вариант B: pandoc + beamer (pdf)
pandoc docs/PRESENTATION.md -t beamer -o docs/GreenPlan_AI.pdf

# вариант C: вручную — перенести тексты слайдов в шаблон pptx ДПиООС
~~~

Скриншоты для плейсхолдеров screens/*.png собрать по чек-листу ниже и положить в docs/screens/.

## 3. Банк вопросов жюри и ответы

| Вопрос | Ответ (тезис) |
|---|---|
| Почему не нейросеть? | ТЗ запрещает чёрный ящик; ядро детерминированное, ML только в объяснимой классификации слоёв с человеком в контуре |
| Как добавить новую норму? | правка data/norms.json (значение + ссылка на пункт), без кода |
| Уникальные имена слоёв? | токены + примеры + геометрия + кадастр-детектор; подтверждение человека запоминается навсегда |
| Доказательство отступов? | interpretation.json: факт/норма/акт/пункт по каждой точке + pytest + сверка в CAD |
| DWG поддержан? | встроенный LibreDWG с кэшем по hash; экзотика → честный fallback отдельным DXF |
| Безопасность данных? | полностью локально и офлайн; ничего не покидает контур |
| Почему без БД? | прозрачность, переносимость, воспроизводимость; JSON-конфиги достаточны |
| Производительность? | секунды на 11 га; профиль железа ТЗ (16/32 ГБ) покрывает тяжёлые подосновы |
| Результаты стабильны? | seed-детерминизм подтверждён тестом; автообучение выключено по умолчанию |
| Бонус-фото? | roadmap сразу после ядра: рендеры строго из итогового DXF (виды + координаты) |

## 4. План Б для демо

1. Заранее прогнать: python -m app.cli run examples/sample_input.dxf --out out_demo
2. Записать скринкаст 60 с: запуск → шаги UI → экспорт → nanoCAD.
3. На сцене: живой прогон; при сбое — открыть out_demo и скринкаст, повествование не прерывается.

## 5. Памятки спикеру

- один слайд = одна мысль; не читать слайд дословно: слайд — тезис, речь — история;
- пауза после каждой цифры со слайда «Ценность в цифрах»;
- на вопрос «чего нет» отвечать формулой «граница осознанная + план закрытия»;
- финал всегда возвращать к призыву: пилот на объектах ДПиООС;
- демо-стенд: второй монитор с UI, терминал с ./run.sh, nanoCAD с открытым result.dxf.
