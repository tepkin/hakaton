# GreenPlan AI

Сервис автоматического проектирования озеленения города с учётом расположения
подземных коммуникаций и городской среды. Принимает DXF/DWG геоподосновы,
строит нормативные зоны допустимой посадки, генерирует воспроизводимый план
деревьев и кустарников и возвращает результат в DXF **на отдельных слоях**,
не изменяя исходные. Каждая посадка сопровождается машиночитаемым обоснованием
со ссылкой на нормативный акт и пункт (СП 42.13330.2016, 743-ПП, 623-ПП/МГСН).

Кейс ДПиООС Москвы · пилот «20 улиц» · полностью офлайн · Docker по ТЗ.

## Быстрый старт

~~~bash
# Docker (требование ТЗ; офлайн — через greenplan_docker.tar)
./run_docker.sh                      # или: docker compose up --build

# Linux (МосТех.ОС / Ubuntu / ROSA), без sudo
./run.sh                             # сам поднимет окружение и сервер :8000

# Windows
run.bat

# CLI (минимальный путь по ТЗ)
python -m app.cli run examples/sample_input.dxf --out out
python -m app.cli doctor             # проверка окружения и конвертера DWG
~~~

Веб-интерфейс: http://127.0.0.1:8000 · Swagger: http://127.0.0.1:8000/docs

## Результат и слои

- GREEN_AI_TREES, GREEN_AI_SHRUBS — предложенные посадки;
- GREEN_AI_ZONES_ALLOWED, GREEN_AI_ZONES_FORBIDDEN — зоны допустимости;
- исходные слои не изменяются (проверяется тестом послойно);
- interpretation.json — обоснования по каждой точке (НПА + пункт + факты);
- estimate.json, summary.json — смета и сводка расчёта.

## Интерпретируемость (пример)

~~~
T-042 · Липа мелколистная · Разрешено
[OK] Проезжая часть: 6.8 м при норме >= 5 м — СП 42.13330.2016, п. 9.3
[OK] Водопровод:     3.4 м при норме >= 2 м — 743-ПП, прил. 3, табл. 2
~~~

## Нормативное ядро

| НПА | Пример пункта |
|---|---|
| СП 42.13330.2016 | п. 9.3: деревья ≥ 5 м, кустарники ≥ 3 м от проезжей части |
| 743-ПП | прил. 3, табл. 2: водопровод ≥ 2 м / ≥ 1 м |
| 623-ПП / МГСН | отступы от зданий, окон, снегоскладов |

Добавление нормы = правка data/norms.json без изменения кода.

## Параметры расчёта

- тип территории Т1–Т8; seed (воспроизводимость);
- бюджет: ТСН / вручную / без лимита; политики warn / optimize / strict;
- наполненность озеленением, % (ползунок); до-заполнение по реестру посадок;
- мастер маппинга слоёв с обучением на подтверждениях эксперта.

## Документация

- docs/ARCHITECTURE.md — компоненты и потоки данных;
- docs/BPMN.md — схема процесса (BPMN-эквивалент) от входа до выхода;
- docs/PRESENTATION.md — презентация (Marp, 19 слайдов, заметки спикера);
- docs/PRESENTATION_KIT.md — чек-листы скриншотов, банк вопросов, сборка pptx/pdf;
- README_DOCKER.md — Docker-развёртывание и офлайн-перенос образа.

## Ограничения и roadmap

- нет слоя границы → выпуклая оболочка с предупреждением;
- экзотические DWG → отдельный DXF с пометкой (исходник не портится);
- далее: фоторендеры из итогового DXF, редактирование точек с перевалидацией,
  пакетные прогоны пилота, интеграция data.mos.ru.
